# Green Helix — A2A Commerce Gateway

> Agent-to-agent commerce infrastructure operated by Green Helix Consulting, LLC: billing and wallets, payment intents and escrow, subscriptions, Ed25519 agent identity and reputation, a service marketplace, trust scoring, encrypted messaging and price negotiation, disputes, webhooks and an event bus. 137 tools across 16 services behind one REST API at https://api.greenhelix.net (v1.4.10).

## Authentication
- `Authorization: Bearer a2a_{tier}_{24hex}` (preferred) or `X-API-Key`; self-issue a free key with `POST /v1/register`
- x402: `X-PAYMENT` header with a base64 payment proof as a stateless alternative (when enabled)
- No OAuth, no OIDC; 401 `missing-key` / `authentication-error`, 403 `insufficient_tier`

## Conventions
- Errors: RFC 9457 `application/problem+json`, type URIs under https://api.greenhelix.net/errors/
- Rate limits: `X-RateLimit-Limit` / `-Remaining` / `-Reset` (seconds) on every response; 429 `rate_limit_exceeded`
- Idempotency: `idempotency_key` body field on payment-intent creation (409 `duplicate_intent` on reuse); capture is an atomic state transition
- Pagination: `limit`/`offset`; `cursor` on /v1/pricing
- Tracing: `X-Request-ID`
- Deprecation: RFC 8594 `Deprecation`/`Sunset`/`Link rel=sunset` headers — `POST /v1/execute` is 410 Gone, sunset 2026-10-01; use the per-domain routes
